# Derin Öğrenme Ödevi: CNN'in Temel Yapısı (Fashion-MNIST)

Konvolüsyon, pooling, ReLU, Softmax, Flatten ve Dense katmanlarının incelenmesi.
Makale: *Classifying Garments from Fashion-MNIST Dataset Through CNNs* (Henrique ve ark., 2021).

## Klasör yapısı
- `kod/` Python dosyaları (her ödev bölümü için bir dosya)
- `cikti/` Grafikler ve deney tablosu (kodlar çalışınca oluşur)
- `rapor/` Word raporu ve sunum

## Çalıştırma
```
pip install -r requirements.txt
python kod/bolum3_konvolusyon.py
python kod/bolum4_pooling.py
python kod/bolum5_relu_softmax.py
python kod/bolum6_cnn.py
python kod/bolum8_deney.py
```
